# Pante – Meme with Utility

A Web3 project that merges meme culture with real-world utility through a comprehensive DeFi ecosystem. This repository contains the frontend code and documentation for the Pante dApp, featuring scroll-activated reveal effects, a sleek side menu, and modern cyber-inspired styling.

## 📌 Overview
Pante is designed to bridge the gap between meme tokens and decentralized finance (DeFi). The project includes:
- A decentralized exchange (DEX) for token swapping
- Liquidity mining and staking mechanisms
- Governance capabilities for token holders
- A modern, responsive interface with scroll effects, RGB gradient animations, and transparent navigation

## ✨ Key Features
- **Scroll Reveal**: Content fades in and slides up as users scroll down the page.
- **Moving RGB Line**: A thin, continuously moving gradient line runs across the top of the page.
- **Responsive Menu**: Side menu slides in from the right; menu links are displayed in white for clarity.
- **Click Effects**: Subtle ripple animations on feature cards and menu items.
- **Transparent Borders**: All major sections have a thin orange border (hex: #ff9500) for visual distinction.
